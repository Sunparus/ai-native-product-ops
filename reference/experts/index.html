    Efficient source strategy¶

    • Compress, don't read cover-to-cover. Drop a book's PDF or a long paper into NotebookLM — use its Audio Overview to absorb the core argument in ~15 minutes, then ask targeted follow-up questions.
    • One podcast, weekly. Latent Space tracks architecture-level shifts (not product hype) — 30–40 min per episode.
    • One primary-source report, quarterly. Stanford HAI's AI Index Report and Epoch AI's compute trend data — read the executive summary only.
    • Skip general-purpose MOOCs. Targeted talks (Karpathy's "Intro to LLMs", ~1 hour) outperform multi-week courses for conceptual grounding.
