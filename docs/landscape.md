# Landscape

## Top 5 Open Questions (2025–2030)

1. **Cost-performance curve** — Will inference cost keep falling fast enough to sustain enterprise-scale adoption, or does it plateau?
2. **Reliability at scale** — Can evaluation and verification tooling close the hallucination gap enough for high-stakes automation?
3. **Sovereign capability gap** — Will EU/regional providers reach frontier-model capability, or does sovereignty require accepting a performance discount?
4. **Safe multi-agent orchestration** — How do multi-agent systems fail predictably and stay auditable once they act autonomously in production?
5. **Standardization vs. lock-in** — Will open protocols (e.g. MCP) create real interoperability, or become a new layer of vendor lock-in?

## Top 5 Current Trends

1. **Agentic architectures** — Shift from single-shot prompting to multi-step, tool-using agents as the default design pattern.
2. **Inference cost collapse** — Smaller, distilled, and open-weight models closing the gap with frontier models at a fraction of the cost.
3. **Sovereign infrastructure buildout** — EU-hosted and open-weight offerings maturing as compliance-driven alternatives.
4. **Interoperability protocols** — Standards like MCP reducing custom integration work between models, tools, and data sources.
5. **System-level evaluation** — Evaluation maturing from academic benchmarks into a production discipline (LLMOps).

## Top 5 Companies — Leading Architectural Know-How

1. **Anthropic** — Frontier models with enterprise-grade API architecture and a safety-first design philosophy.
2. **OpenAI** — Frontier model capability at ecosystem scale, broad tooling and plugin surface.
3. **Google DeepMind / Google Cloud** — Vertical integration from custom silicon (TPU) through model to cloud infrastructure.
4. **Mistral AI** — EU-based, open-weight models — a reference point for sovereignty-conscious architecture.
5. **NVIDIA** — Owns the compute and inference-serving layer (GPUs, TensorRT, Triton) underneath nearly every other player.
